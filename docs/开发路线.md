# 开发路线

## 总体原则

- 每个阶段结束时项目都可以构建和启动。
- 每个阶段先完成数据库迁移和领域测试，再接 HTTP 或前端。
- 不一次性写完所有模块后集中排查。
- 涉及外部 DNS、TLS 和对象存储的能力必须提供本地替代实现。
- 没有真实测试数据的功能不进入“已完成”状态。

## 当前技术债

- 点击分析直接查询 `click_events` 明细，尚未建立预聚合表。
- 自定义域名尚未完成公网 DNS 和 HTTPS 端到端验收。
- 前端使用 `localStorage` 保存 Token，生产部署需要评估 HttpOnly Cookie
  和 CSRF 防护。
- Prometheus 已覆盖 HTTP、Stream 和 Worker；缓存命中率、限流拒绝和 MySQL 连接池指标仍未实现。
- 仓库尚未配置自动化密钥扫描，提交前依赖人工检查。
