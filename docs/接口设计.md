# 接口设计

## 1. 通用约定

Base URL：

```text
/api/v1
```

认证：

```http
Authorization: Bearer <access_token>
```

每个响应包含：

```http
X-Request-ID: <request-id>
```

错误响应：

```json
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "human readable message",
    "request_id": "..."
  }
}
```

时间统一使用 RFC 3339 UTC 格式。

## 2. 已实现接口

### 注册

```http
POST /api/v1/auth/register
```

请求：

```json
{
  "email": "user@example.com",
  "password": "password123",
  "display_name": "User"
}
```

响应：`201 Created`

```json
{
  "user": {
    "id": "01...",
    "email": "user@example.com",
    "display_name": "User",
    "role": 1,
    "created_at": "2026-11-12T10:00:00Z"
  },
  "workspace": {
    "id": "01...",
    "name": "User 的空间",
    "slug": "ws_01...",
    "created_at": "2026-11-12T10:00:00Z"
  },
  "token": {
    "access_token": "<jwt>",
    "token_type": "Bearer",
    "expires_at": "2026-11-12T10:15:00Z",
    "refresh_token": "srt_..."
  }
}
```

错误：

| HTTP | Code | 场景 |
| --- | --- | --- |
| 400 | `INVALID_INPUT` | 邮箱、密码或名称不合法 |
| 409 | `EMAIL_EXISTS` | 邮箱已注册 |

### 登录

```http
POST /api/v1/auth/login
```

请求：

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

响应：`200 OK`，结构与注册相同。

### 刷新令牌

```http
POST /api/v1/auth/refresh
```

请求：

```json
{
  "refresh_token": "srt_..."
}
```

响应：`200 OK`，返回新的 Access Token 和 Refresh Token。

旧 Refresh Token 再次使用返回：

```json
{
  "error": {
    "code": "REFRESH_TOKEN_REUSED",
    "message": "refresh token has already been used",
    "request_id": "..."
  }
}
```

### 退出

```http
POST /api/v1/auth/logout
```

请求：

```json
{
  "refresh_token": "srt_..."
}
```

响应：`204 No Content`。

### 当前用户

```http
GET /api/v1/me
Authorization: Bearer <access_token>
```

响应：

```json
{
  "user": {},
  "workspace": {}
}
```

### 修改资料

```http
PATCH /api/v1/me
Authorization: Bearer <access_token>
```

请求：

```json
{
  "display_name": "New name"
}
```

响应：`200 OK`。

## 3. 规划接口

### 链接

```text
POST   /api/v1/links
GET    /api/v1/links
GET    /api/v1/links/{id}
PATCH  /api/v1/links/{id}
DELETE /api/v1/links/{id}
```

### 公开跳转

```text
GET /{slug}
GET /r/{slug}
```

具体路径根据 Host 和域名配置解析。

### 域名

```text
POST   /api/v1/domains
GET    /api/v1/domains
GET    /api/v1/domains/{id}
POST   /api/v1/domains/{id}/verify
DELETE /api/v1/domains/{id}
```

### 二维码

```text
POST /api/v1/links/{id}/qr-codes
GET  /api/v1/qr-codes/{id}
GET  /api/v1/qr-codes/{id}/image
```

### 分析

```text
GET /api/v1/analytics/overview
GET /api/v1/links/{id}/analytics
GET /api/v1/analytics/share/{token}
```

### API Key 与 Webhook

```text
GET    /api/v1/api-keys
POST   /api/v1/api-keys
DELETE /api/v1/api-keys/{id}

GET    /api/v1/webhooks
POST   /api/v1/webhooks
PATCH  /api/v1/webhooks/{id}
DELETE /api/v1/webhooks/{id}
```
