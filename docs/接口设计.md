# 接口设计

## 1. 通用约定

Base URL：

```text
/api/v1
```

认证：

```http
Authorization: Bearer <access_token>
```

每个响应包含：

```http
X-Request-ID: <request-id>
```

错误响应：

```json
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "请求参数无效",
    "request_id": "..."
  }
}
```

时间统一使用 RFC 3339 UTC 格式。

## 2. 已实现接口

### 注册

```http
POST /api/v1/auth/register
```

请求：

```json
{
  "email": "user@example.com",
  "password": "password123",
  "display_name": "User"
}
```

响应：`201 Created`

```json
{
  "user": {
    "id": "01...",
    "email": "user@example.com",
    "display_name": "User",
    "role": 1,
    "created_at": "2026-11-12T10:00:00Z"
  },
  "workspace": {
    "id": "01...",
    "name": "User 的空间",
    "slug": "ws_01...",
    "created_at": "2026-11-12T10:00:00Z"
  },
  "token": {
    "access_token": "<jwt>",
    "token_type": "Bearer",
    "expires_at": "2026-11-12T10:15:00Z",
    "refresh_token": "srt_..."
  }
}
```

错误：

| HTTP | Code | 场景 |
| --- | --- | --- |
| 400 | `INVALID_INPUT` | 邮箱、密码或名称不合法 |
| 409 | `EMAIL_EXISTS` | 邮箱已注册 |

### 登录

```http
POST /api/v1/auth/login
```

请求：

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

响应：`200 OK`，结构与注册相同。

### 刷新令牌

```http
POST /api/v1/auth/refresh
```

请求：

```json
{
  "refresh_token": "srt_..."
}
```

响应：`200 OK`，返回新的 Access Token 和 Refresh Token。

旧 Refresh Token 再次使用返回：

```json
{
  "error": {
    "code": "REFRESH_TOKEN_REUSED",
    "message": "refresh token has already been used",
    "request_id": "..."
  }
}
```

### 退出

```http
POST /api/v1/auth/logout
```

请求：

```json
{
  "refresh_token": "srt_..."
}
```

响应：`204 No Content`。

### 当前用户

```http
GET /api/v1/me
Authorization: Bearer <access_token>
```

响应：

```json
{
  "user": {},
  "workspace": {}
}
```

### 修改资料

```http
PATCH /api/v1/me
Authorization: Bearer <access_token>
```

请求：

```json
{
  "display_name": "New name"
}
```

响应：`200 OK`。

## 3. 已实现短链接接口

### 匿名试用

```http
POST /api/v1/trial/links
GET  /api/v1/trial/links
POST /api/v1/trial/claim
```

创建请求：

```json
{
  "destination_url": "https://example.com/landing",
  "alias": "launch",
  "title": "活动页面"
}
```

创建接口不要求登录。首次调用通过 HttpOnly `shorturl_trial` Cookie 建立游客
会话，响应包含 `short_url`、`expires_at` 和剩余额度。游客只能使用平台默认
域名，每个会话最多创建 3 条链接，默认 24 小时后失效。

列表接口只返回当前 Cookie 会话创建的链接，不接受工作空间 ID 或其他身份参数。

认领接口要求 Access Token，并从当前请求携带的游客 Cookie 中读取会话。后端在
同一 MySQL 事务中将链接和点击明细迁移到当前工作空间，清除临时过期时间，
删除游客会话和游客工作空间，然后失效旧跳转缓存。重复调用或没有游客 Cookie
时返回 `claimed_links: 0`。

```json
{
  "claimed_links": 1,
  "claimed_clicks": 2
}
```

### 创建短链

```http
POST /api/v1/links
Authorization: Bearer <access_token>
```

请求：

```json
{
  "destination_url": "https://example.com/landing",
  "alias": "launch",
  "title": "Launch page",
  "notes": "",
  "redirect_code": 302,
  "starts_at": null,
  "expires_at": null
}
```

响应：`201 Created`

```json
{
  "id": "01...",
  "slug": "launch",
  "short_url": "http://localhost:18080/r/launch",
  "destination_url": "https://example.com/landing",
  "title": "Launch page",
  "notes": "",
  "status": 1,
  "redirect_code": 302,
  "starts_at": null,
  "expires_at": null,
  "created_at": "2026-11-12T10:00:00Z"
}
```

错误：

| HTTP | Code | 场景 |
| --- | --- | --- |
| 400 | `INVALID_INPUT` | URL、短码或时间范围不合法 |
| 409 | `SLUG_TAKEN` | 自定义短码已被占用 |

### 链接列表

```http
GET /api/v1/links?limit=20&cursor=<opaque-cursor>
Authorization: Bearer <access_token>
```

响应：

```json
{
  "items": [],
  "next_cursor": ""
}
```

### 链接详情、修改和删除

```text
GET    /api/v1/links/{id}
PATCH  /api/v1/links/{id}
DELETE /api/v1/links/{id}
```

### 二维码

```http
GET /api/v1/links/{id}/qr?format=png&size=512
Authorization: Bearer <access_token>
```

- `format` 支持 `png`、`svg`。
- `size` 有效范围为 128 至 1024。
- 二维码编码完整短链地址并附带 `utm_source=qr`。
- 修改目标地址后二维码内容不变，仍然可以正常跳转。

修改请求的字段均可选：

```json
{
  "destination_url": "https://example.com/new-page",
  "title": "New title",
  "notes": "new notes",
  "status": 1,
  "redirect_code": 301,
  "expires_at": "2026-12-31T23:59:59Z",
  "clear_expires_at": false
}
```

### 公开跳转

```http
GET /r/{slug}
```

有效链接返回 `301` 或 `302`。不存在、已删除或尚未生效返回 `404`，
停用或过期返回 `410`。已删除资源统一返回 `404`，避免向外暴露删除历史。

### 点击分析

工作空间总览：

```http
GET /api/v1/analytics/overview?days=7
Authorization: Bearer <access_token>
```

`days` 有效范围为 1 至 90。响应包含：

- 未删除链接总数和当前有效启用链接数。
- 时间范围内总点击、未命中 UA 规则点击、疑似机器人点击和独立访客。
- 工作空间整体点击趋势。
- 点击量最高的 5 条链接。

查询始终按当前 Token 中的工作空间隔离，不接受客户端提交的 workspace ID。

```http
GET /api/v1/links/{id}/analytics?days=30
Authorization: Bearer <access_token>
```

`days` 有效范围为 1 至 90。响应包含：

- 总点击、未命中 UA 规则的点击、疑似机器人点击和独立访客。
- 按小时或按天的点击趋势。
- 国家、设备、操作系统、浏览器和来源排行。

点击事件通过 Redis Streams 异步写入 MySQL，接口允许短暂最终一致。

### 自定义域名

```text
GET    /api/v1/domains
POST   /api/v1/domains
POST   /api/v1/domains/{id}/verify
DELETE /api/v1/domains/{id}
```

添加请求：

```json
{
  "hostname": "go.example.com"
}
```

响应包含：

- 域名状态和 `verified`。
- TXT 记录名和值。
- 需要指向的平台 CNAME。

本地 `DOMAIN_VERIFY_MODE=mock` 时直接模拟成功；`dns` 模式会查询
`_shorturl.{hostname}` TXT 和域名 CNAME。

已验证域名短链使用根路径：

```http
GET /{slug}
Host: go.example.com
```

平台默认域名仍使用 `/r/{slug}`。

### API Key 与 Webhook

API Key 与 Webhook 均已实现。

以下接口只允许平台管理员 JWT 访问。普通用户 JWT 返回 403，API Key 也不能
管理这些后台配置。

```text
GET    /api/v1/api-keys
POST   /api/v1/api-keys
DELETE /api/v1/api-keys/{id}

GET    /api/v1/webhooks
POST   /api/v1/webhooks
DELETE /api/v1/webhooks/{id}
GET    /api/v1/webhooks/{id}/deliveries
```

API Key 创建请求：

```json
{
  "name": "部署脚本",
  "scopes": ["links:read", "analytics:read"]
}
```

创建响应中的 `secret` 只返回一次。后续使用：

```http
Authorization: Bearer sl_live_<prefix>.<secret>
```

也支持 `X-API-Key` Header。API Key 可以访问短链和分析资源，但不能访问资料、
域名、游客认领或 API Key 管理接口。

Webhook 创建请求：

```json
{
  "name": "订单服务",
  "url": "https://hooks.example.com/shorturl"
}
```

创建响应中的 `secret` 只返回一次。停用端点使用 `DELETE`，状态转换为停用，
同时把该端点待投递任务标记为终止。投递记录接口支持 `limit=1..100`。

Webhook 请求头：

```text
X-ShortURL-Event-ID
X-ShortURL-Event-Type
X-ShortURL-Timestamp
X-ShortURL-Signature
```

`X-ShortURL-Signature` 的值为
`sha256=HEX(HMAC-SHA256(secret, timestamp + "." + body))`。接收方应校验时间戳
窗口、HMAC 和 Event ID 幂等键。

### 滥用治理

公开举报：

```text
POST /api/v1/abuse/reports
```

```json
{
  "short_url": "https://short.example.com/r/abcd",
  "reason": "phishing",
  "details": "页面冒充登录入口"
}
```

管理员治理接口只允许平台管理员 JWT：

```text
GET    /api/v1/abuse/reports?status=1&limit=20
POST   /api/v1/abuse/reports/{id}/resolve
GET    /api/v1/abuse/blocked-domains
POST   /api/v1/abuse/blocked-domains
DELETE /api/v1/abuse/blocked-domains/{id}
```

裁决请求：

```json
{
  "decision": "takedown",
  "note": "管理员审核确认违规"
}
```

`takedown` 会在同一事务中停用短链、关闭举报并写审计日志；提交后删除 Redis
跳转缓存。`reject` 只关闭举报并写审计日志。
