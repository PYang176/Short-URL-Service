# 短链接平台需求规格

## 1. 项目定位

当前代码实现一个单用户工作空间短链接平台，包含短链管理、公开跳转、点击
采集、单链接分析、二维码导出、API Key、Webhook 和 OpenAPI 文档。文件夹、
标签等能力属于目标范围，尚未进入运行代码。

本文同时定义当前验收基线和后续目标范围。已实现功能以 README、路由和数据库
迁移为准；规划功能不能视为当前交付能力。

当前工程范围：

- 短链管理、缓存跳转、点击采集和单链接分析形成可运行主链路。
- 跳转路径具备缓存一致性、Redis 限流和 Redis 故障降级策略。
- 点击事件通过 Redis Streams 异步写入 MySQL，Worker 支持 Pending 接管。
- 自定义域名支持 TXT/CNAME 校验和 Host 路由，公网 DNS/TLS 另行验收。
- 公开举报、管理员下架、目标域名黑名单和审计日志形成治理闭环。
- 当前自动化覆盖单元测试、真实 MySQL 集成、浏览器 E2E 和 k6 跳转压测。

## 2. 角色

| 角色 | 能力 |
| --- | --- |
| 访客 | 访问短链接、通过密码页访问受保护链接、查看公开分享报表 |
| 注册用户 | 管理自己的工作空间、短链、二维码和访问分析 |
| 平台管理员 | 管理域名、API Key、Webhook、后台指标和高风险操作 |

当前为单用户工作空间模型。核心表包含工作空间归属，但团队角色和管理员治理
尚未实现。

普通用户界面只展示工作台、短链、二维码和访问分析。高级配置接口在服务端
校验平台角色，不能只依赖前端隐藏入口。

## 3. 范围

### 3.1 第一阶段目标范围

以下条目是产品目标范围，不代表全部已经实现。当前完成状态以 README 的
“已实现”和“当前边界”为准。

#### 用户与认证

- 邮箱和密码注册。
- 登录、退出。
- 短期 Access Token 和可轮换 Refresh Token。
- Refresh Token 保存哈希，支持撤销和重放检测。
- 用户资料查询和修改。
- 登录、注册和刷新接口限流。

#### 工作空间

- 每个用户注册时自动创建工作空间。
- 链接、域名、二维码和统计均归属工作空间。
- 所有管理接口必须校验资源归属。

#### 短链接

- 使用目标 URL 创建短链接。
- 支持随机短码和自定义别名。
- 支持标题、备注、文件夹、标签。
- 支持 301、302 跳转。
- 支持立即生效和定时生效。
- 支持过期时间和自定义过期落地页。
- 支持点击次数上限。
- 支持密码保护。
- 支持动态修改目标 URL，短链保持不变。
- 支持停用、恢复和软删除。
- 支持列表、搜索、状态筛选和分页。
- 随机短码生成必须处理并发冲突。
- 自定义别名冲突返回 HTTP 409。
- 创建接口支持 `Idempotency-Key`。

#### 公开跳转

- 根据 Host 和路径解析自定义域名及短码。
- 有效链接返回 301 或 302。
- 不存在返回 404。
- 已过期返回 410，或跳转到配置的过期地址。
- 未到生效时间展示“尚未开始”页面。
- 停用链接返回 410。
- 密码链接展示密码验证页面。
- 密码验证成功后签发短期访问凭证。
- 机器人点击单独统计，不消耗人类点击上限。
- 跳转成功后将点击事件写入 Redis Stream。
- 点击统计故障不得阻断正常跳转。

#### 缓存

- Redis 缓存链接跳转所需的最小信息。
- 缓存包含目标、状态、生效时间、过期时间、密码标记和路由配置版本。
- 缓存不存在的数据，防止缓存穿透。
- 使用 `singleflight` 合并热点链接回源。
- TTL 增加随机抖动，防止缓存集中失效。
- 修改、停用、删除链接或域名后主动失效缓存。
- Redis 不可用时降级到 MySQL。
- 监控缓存命中率、回源次数和 Redis 错误。

#### 自定义域名

- 工作空间可以添加自定义域名。
- 系统生成 TXT 所有权验证记录。
- 系统生成 CNAME 接入说明。
- Worker 异步验证 DNS 所有权和 CNAME。
- 支持验证中、成功、失败、停用状态。
- 已验证域名通过 Host 路由短链。
- 默认域名和多个自定义域名可以同时工作。
- 删除域名后该域名链接停止跳转。
- 域名重新添加和释放时防止旧验证记录造成抢注。
- 生产环境通过 Caddy On-Demand TLS 接入 HTTPS。
- 未验证域名不得触发证书申请。
- 开发环境通过 Fake DNS Resolver 模拟验证，不开放模拟接口到生产。

#### 二维码

- 短链接可以生成动态二维码。
- 二维码编码稳定的短链地址，修改目标后二维码仍然有效。
- 同一链接可以创建多个二维码。
- 支持前景色、背景色、点样式、角样式和 Logo。
- 支持 PNG、SVG、JPEG 导出。
- 支持二维码预览。
- 扫码点击与分析事件关联。
- Logo 存放在对象存储中。

#### 点击分析

- 记录事件 ID、链接、二维码、时间、域名、访客哈希和路由变体。
- 记录国家、地区、城市、设备、操作系统、浏览器和语言。
- 记录 Referer、UTM 参数和机器人标记。
- 不保存原始 IP。
- 查询总点击、人类点击、机器人点击和独立访客。
- 支持按小时、天、周统计趋势。
- 支持国家、设备、系统、浏览器、语言、Referer 和 UTM 分布。
- 支持链接、文件夹、域名和标签过滤。
- 已实现点击明细的时间、链接、真人/机器人、设备、国家、浏览器和 UTM 组合筛选。
- 已实现通过数据库游标流式导出 CSV，不包含原始 IP 或访客哈希。
- 支持可分享的只读分析报表。
- 统计最终一致，目标为事件发生后 10 秒内可查询。

流量分类口径：

- 当前不接入外部机器人识别服务或第三方识别包。
- `is_bot` 仅表示 User-Agent 是否命中项目内手写的子串规则。
- `human_clicks` 的准确含义是“未命中当前 UA 规则的点击”，不代表已验证真人。
- 当前规则存在误判和漏判，产品界面应使用“疑似机器人”口径。

#### 组织与批量操作

- 文件夹创建、重命名和删除。
- 标签创建、删除和链接关联。
- CSV 同步批量创建链接，返回逐行成功或失败结果。
- CSV 批量导出链接与统计数据。
- 批量任务异步执行并返回任务状态。

#### API 与 Webhook

- 提供 OpenAPI 3.1 文档。
- 平台管理员可创建、撤销 API Key。
- API Key 只在创建时返回明文，数据库保存哈希。
- API 请求按 Key 和 IP 限流。
- 平台管理员可创建、查询和停用 Webhook；停用后终止待投递任务。
- Webhook 请求使用 HMAC 签名。
- Webhook 失败使用指数退避重试。
- 连续失败达到阈值后自动停用。
- 链接写入与 Webhook Outbox 必须在同一个 MySQL 事务中提交。

#### 安全与治理

- URL 只允许 HTTP 和 HTTPS。
- 校验 URL 长度、主机名和非法控制字符。
- 拒绝用户信息嵌入等高风险 URL 形式。
- 保留路径不能被注册为短码。
- 密码使用 Argon2id。
- 密码尝试单独限流。
- 提供恶意域名和链接黑名单。
- 支持公开提交滥用举报，管理员确认后在同一事务中下架链接。
- 域名黑名单匹配精确域名及其子域名，并阻止后续创建和修改。
- 管理员下架和黑名单操作写入审计日志。
- 管理员可以禁用链接、域名和用户。
- 重要管理操作写入审计日志。
- 日志中不输出密码、Token、API Key 和原始 IP。

#### 可视化

- 免登录工具页通过悬浮对话框完成登录和注册，不单独跳转表单页面。
- 工作空间概览。
- 链接列表、搜索、筛选和分页。
- 创建和编辑链接。
- 链接分析详情。
- 二维码设计器和导出。
- 域名管理与 DNS 验证状态。
- 文件夹和标签管理。
- API Key 与 Webhook 配置。
- 公共只读报表。
- 基础管理员治理页面。
- 支持桌面端和移动端。

#### 工程与运维

- MySQL 使用版本化迁移。
- Docker Compose 启动 Redis、API、Worker 和迁移任务，MySQL 使用外部实例。
- API 与 Worker 可分进程运行。
- 健康检查、就绪检查和 Prometheus 指标。
- 结构化日志和请求 ID。
- 优雅退出，等待在途请求和消息批次处理完成。
- Go 单元测试、集成测试、`-race`、lint 和 CI。
- k6 压测脚本和可复现报告。

### 3.2 第二阶段

- 按国家、地区、设备、浏览器、语言和 UTM 参数配置跳转规则。
- A/B 测试和结果对比。
- 团队成员和基础角色权限。
- 自定义社交分享预览。
- 链接点击上限的 Redis 近实时限制。

### 3.3 本期不做

- Link-in-Bio 页面编辑器。
- 支付、订阅、套餐配额和发票。
- 自有移动 App 的 Universal Link/App Link。
- Chrome 扩展、移动端 SDK 和 MCP Server。
- URL Cloaking。
- Meta、Google、TikTok 等广告像素。
- AI 生成短码或摘要。

## 4. 非功能需求

### 4.1 性能

- 缓存命中的公开跳转路径以单机 1,000 QPS 为首个验收目标。
- 最终结果以固定硬件环境和 k6 实测报告为准。
- 点击消费支持批量写入，不按单条事件同步写数据库。
- 管理接口与公开跳转接口分别限流。

### 4.2 可用性

- Redis 或统计链路故障不能让公开跳转不可用。
- 数据库不可用时就绪检查失败，但不影响已启动进程的正常退出。
- Worker 重启后能够接管 Pending 点击事件。
- Webhook 和域名验证失败可重试。

### 4.3 一致性

- 链接元数据以 MySQL 为准。
- 目标 URL 修改后，缓存立即失效。
- 点击分析为最终一致，不参与跳转判定。
- 点击上限允许秒级最终一致，超出后短时间内可能继续跳转。

### 4.4 可观测性

至少提供以下指标：

- HTTP 请求量、延迟和状态码。
- 缓存命中、未命中、回源和 Redis 错误。
- 短码冲突和创建幂等命中。
- Stream 长度、Pending 数和消费延迟。
- 点击消费成功、失败和重复事件。
- Webhook 投递成功率和失败率。
- 域名验证成功率和耗时。
- MySQL 连接池状态。

### 4.5 隐私

- 不保存访客原始 IP。
- 访客哈希使用可轮换的每日盐。
- 提供分析数据保留策略。
- 分享报表不暴露工作空间内部标识。

## 5. 验收场景

1. 用户注册后创建短链，访客通过默认域名访问并成功跳转。
2. 两个并发请求使用同一个自定义别名，只有一个成功，另一个返回 409。
3. 携带相同 `Idempotency-Key` 重试创建，不会产生重复链接。
4. 链接目标修改后，旧缓存立即失效。
5. 过期、停用、未开始和密码保护链接的行为符合定义。
6. Redis 命中路径和 Redis 宕机降级路径都能正确跳转。
7. 点击事件写入 Stream，Worker 重启后可以恢复 Pending 事件。
8. 分析页在事件发生后 10 秒内显示点击。
9. 二维码在目标链接修改后仍然有效。
10. Fake DNS 验证成功、失败、超时和越权场景均有测试。
11. 已验证域名通过 Host 头正确路由，未验证域名不能路由。
12. API Key 只显示一次，撤销后立即失效。
13. Webhook 签名正确，失败后按退避策略重试。
14. 用户不能读取或修改其他工作空间的任何资源。
15. 在已准备好的外部 MySQL 和 Docker Compose Redis/API/Worker 环境中，可以完成注册、创建、跳转和查看分析。
16. 访客可以举报有效短链，管理员下架后 Redis 缓存失效且跳转返回 410。

## 6. 完成定义

一项功能只有同时满足以下条件才算完成：

- 数据库迁移可执行。
- 后端接口和权限校验完成。
- 前端交互完成。
- 单元测试和必要的集成测试完成。
- 错误码和 OpenAPI 文档更新。
- 关键操作产生日志和指标。
- Docker 环境可运行。
- README 或对应文档同步更新。
