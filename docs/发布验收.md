## 7. 已知边界

- 点击分析直接查询 MySQL 明细，尚未建立预聚合表。
- 机器人标记基于 User-Agent 子串规则，只表示“疑似机器人”，不代表验证真人。
- 浏览器使用 `localStorage` 保存 Token，生产公网部署前仍需评估 HttpOnly
  Cookie 与 CSRF 防护。
- 自定义域名已完成本地 TXT/CNAME 校验和 Host 路由，公网 DNS 与自动 HTTPS
  证书尚未验收。
- Redis Streams 点击消费采用至少一次语义，通过事件 ID 唯一约束处理重复消费。
- 缓存失效在数据库提交后使用独立的有界 Context 重试；如果 Redis 长时间不可用，
  仍需通过后续运维操作确认旧缓存已被清除。
- 压测结果是当前单机、缓存命中、同机压测场景的数据，不能直接推导生产容量。
